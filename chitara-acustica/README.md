# Chitara acustică virtuală

Sursa acestei lecții este inclusă în proiectul Praxis-Fizica. Buildul și importul în aplicația Web se rulează din directorul proiectului:

```powershell
npm run import:guitar
```

Lecția nu folosește un API Gemini sau variabile de mediu. Browserul cere acces la microfon numai când utilizatorul pornește acordorul sau analizorul live.
