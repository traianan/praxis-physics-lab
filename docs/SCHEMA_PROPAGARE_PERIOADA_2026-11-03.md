# Propagarea perturbației pe durata unei perioade

Adăugată în Bazele undelor → Modelul undă plană → Propagarea într-o perioadă, imediat după Lungimea de undă. Schema SVG este refăcută după fotografia trimisă de utilizator, figura 1.3.1.7, și păstrează cele șase momente: 0, T/4, T/2, 3T/4, T și 5T/4.

Sursa A oscilează armonic. Fiecare curbă este calculată cu y/A=sin[2π(t/T−x/λ)] în regiunea atinsă x≤vt și este zero în fața frontului. Capătul B este desenat la 2λ, dincolo de front în toate cele șase cadre, astfel încât nu este introdusă o reflexie prematură. Săgeata verticală dublă indică direcția oscilației sursei, nu viteza instantanee la punctele de întoarcere.

Cadrul t=T evidențiază distanța λ=v_fT. Etichetele timpului folosesc fracții MathML, iar v_f are indice SVG. La desktop cadrele ocupă trei coloane și două rânduri; pe ecrane înguste se rearanjează, păstrând dimensiunea textului și derularea locală a desenului dacă este necesară.

Verificări: trei teste noi pentru profilul cauzal în toate cele șase etape, distanța parcursă, pozițiile sursei, lipsa perturbației înaintea frontului, descrieri RO/EN și identificatori SVG unici. Suita completă: 313/313 teste trecute. Browser: șase desene, patru fracții ale timpilor, trei coloane la 1366×768, înălțimea schemei aproximativ 476 px; fără erori de randare sau overflow orizontal al paginii în cele șase configurații de ecran/text verificate. Arhiva autonomă Unde mecanice a fost regenerată.

Reproducere: `node scripts/qa/scientific-math-browser.mjs --course=unde-mecanice --propagation --matrix`.
