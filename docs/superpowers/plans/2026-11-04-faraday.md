# Faraday Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** Five integrated bilingual Faraday experiments with validated physics and local resources.
**Architecture:** Pure SI models; one controller clock per active experiment; independent Canvas view; shared Praxis chrome and localization.
**Tech Stack:** Native JavaScript modules, Canvas 2D, Node test runner; no new production dependency.
**Spec:** ../specs/2026-11-04-faraday-design.md (approved by user).

## Global Constraints
- Preserve existing user edits; no publication requested. Work on codex/faraday-lab; integrate in the current project.
- Five activities, shared navigation/workspace, RO/EN, SI, original local assets; generator model reused unchanged.
- Mouse and touch emulation, five viewport sizes, text 100/200%, board mode, local export.

## Review Focus
- Drag cancellation and bounds never leave a nonzero velocity at a stationary endpoint.
- Paused/background/hidden activity cannot accumulate time or energy.
- RL switching preserves current and energy; invalid parameters cannot propagate NaN.
- Language, palette and resize preserve experiment state.
- Export contains shared dependencies and works without network access to external services.
