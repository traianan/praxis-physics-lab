Ex. 1.4.2 Încălzirea oxigenului într-un vas de volum constant

Într-un vas de volum constant se află o cantitate de oxigen de masă m = 1 g și căldură specifică izocoră c_V = 700 J/(kg·K), la temperatura t = 27 °C și presiunea p₁ = 100 kPa. Aflați căldura Q necesară pentru încălzirea oxigenului, astfel încât presiunea sa să devină p₂ = 200 kPa.

    Eroare în manual Manualul scrie „= 0,7 · 300,15 · 2 J = 420,2 J”. Paranteza este (p₂/p₁ − 1) = (200/100 − 1) = 1, nu 2. Valoarea corectă este Q ≈ 210 J.

      Transformarea adiabatică · Q = 0

      În transformarea adiabatică, prin definiție, gazul nu schimbă căldură cu mediul.

      legea transformării

      Folosind ecuația termică de stare, ecuația transformării adiabactice poate fi rescrisă astfel:

      Iar lucrul mecanic adiabatic se scrie în trei forme echivalente:

      Atunci, conform primului principiu (Q = 0), variația energiei interne este ΔU = ν·C_V·(T_f − T_i) = m·c_V·(T_f − T_i).

      Observații

      1. Ecuația transformării adiabactice a fost obținută în 1823 de Siméon-Denis Poisson.
      2. Exponentul adiabatic este supraunitar: pentru gazul monoatomic γ = 5/3, iar pentru cel biatomic γ = 7/5.
      3. Deoarece γ > 1, în procesul adiabatic presiunea variază în funcție de volum mai rapid decât în transformarea izotermă. De aceea adiabata este înclinată mai puternic decât izoterma și o adiabată și o izotermă se intersectează într-un singur punct.
