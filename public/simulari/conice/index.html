Ce urmărești în animație?

Planul de tăiere traversează conul dublu. Forma curbei de intersecție depinde de unghiul planului față de axa conului.

  • Plan perpendicular pe axă → cerc.
  • Plan înclinat, intersectând o singură pânză → elipsă.
  • Plan paralel cu o generatoare → parabolă.
  • Plan care taie ambele pânze → hiperbolă, cu două ramuri.

✦ Definiția unificată: focar și directoare

DeschideÎnchide

Toate conicele pot fi descrise cu un focar F, o directoare d și un număr pozitiv e, numit excentricitate. Un punct P aparține conicei dacă:

PF / dist(P, d) = e
  • e = 0 → cerc (caz particular de elipsă).
  • 0 < e < 1 → elipsă.
  • e = 1 → parabolă.
  • e > 1 → hiperbolă.
✦Excentricitatea măsoară cât de alungită este curba. Ea controlează forma, nu doar dimensiunea.

∿ Cum recunoști conica dintr-o ecuație?

DeschideÎnchide

Forma generală a unei conice este:

Ax² + Bxy + Cy² + Dx + Ey + F = 0

Discriminantul Δ = B² − 4AC ne spune tipul curbei (în cazul nedegenerat):

  • Δ < 0 → elipsă sau cerc;
  • Δ = 0 → parabolă;
  • Δ > 0 → hiperbolă.

Termenul Bxy apare când conica este rotită față de axele de coordonate. În lecție folosim forma canonică, cu axele paralele cu axele de coordonate.

◎ Elementele principale

DeschideÎnchide
Elipsă: c² = a² − b² · Hiperbolă: c² = a² + b²

a și b sunt semiaxele, iar c este distanța de la centru la focare. La elipsă focarele sunt în interior; la hiperbolă sunt pe axa netraversată de ramuri.

La parabolă, distanța de la vârf la focar este p/2, iar directoarea este simetrică față de vârf.

⌁ De ce "conice"?

DeschideÎnchide

Numele vine din faptul că toate apar prin tăierea unui con circular dublu cu un plan. Un con dublu este format din două pânze care se întâlnesc în vârf.

  • Unghiul planului față de axă schimbă tipul curbei.
  • Poziția planului schimbă dimensiunea și deschiderea ei.
  • Dacă planul trece prin vârf, putem obține cazuri degenerate: un punct, o dreaptă sau două drepte.
↗Încearcă să modifici parametrii din laborator și urmărește cum se schimbă simultan planul, curba și ecuația.

Construcția focală a conicei

Un punct mobil P păstrează raportul dintre distanța la focar și distanța la directoare.

experiment interactiv

focar F directoare d punct mobil P

✧ Controlează forma

Excentricitatea e0,70
Elipsă

0 < e < 1: suma distanțelor la focare este constantă. Aici urmărim definiția echivalentă cu focar și directoare.

r = e·d / (1 + e·cos θ)

Focarul este în origine, iar directoarea are ecuația x = d. Pentru hiperbolă, prima expresie descrie ramura x < d, iar a doua ramura x > d; pentru elipsă și parabolă se folosește prima expresie. Unghiul θ este măsurat față de axa focală.

Citește construcția
  • F este focarul, iar d este directoarea.
  • Segmentul PF este distanța de la punct la focar.
  • Segmentul PD este distanța perpendiculară de la P la directoare.
  • Raportul PF / PD rămâne egal cu excentricitatea.

♻ De ce aceeași definiție funcționează?

Dacă pornești de la un focar și o directoare, mulțimea punctelor cu raport constant este exact o conică. Schimbând doar valoarea lui e, treci continuu de la cerc la elipsă, apoi la parabolă și hiperbolă.

cerc → elipsă → parabolă → hiperbolă

🎚 Sugestii de explorare

  • Setează e = 0 și observă cercul.
  • Crește lent spre e = 1: elipsa devine tot mai alungită.
  • La e = 1, a doua ramură fuge la infinit și rămâne parabola.
  • Pentru e > 1 apar două ramuri: hiperbola.

Orbita Pământului

Excentricitatea orbitei Pământului este aproximativ 0,0167, deci traiectoria este aproape circulară. Soarele se află în focarul F₁, iar F₂ este foarte aproape de el.

cinematicaparabolă

Mișcarea proiectilului

Fără rezistența aerului, traiectoria unui proiectil lansat oblic este o parabolă. Componenta orizontală a vitezei rămâne constantă.

y = x·tan α − g·x² / (2v₀²·cos²α)
navigațiehiperbolă

Localizare prin diferență de timp

Sistemele de navigație compară momentele în care ajunge un semnal de la două stații. Locurile cu aceeași diferență de timp formează o hiperbolă.

|PF₁ − PF₂| = 2a = constant
opticăparabolă

Antene și concentratoare solare

Razele paralele cu axa unei parabole se reflectă spre focar. De aceea antenele satelit și concentratele solare au formă parabolică.

d(P, F) = d(P, directoare)
mișcare periodicăcerc

Mișcarea circulară uniformă

Un corp care se mișcă pe un cerc cu modulul vitezei constant are accelerație orientată spre centru. Cercul este cazul particular al elipsei cu focarele confundate.

Vezi laboratorul mișcării circulare →
a = v² / r, x² + y² = r²

Galerii de șoapte și unde

Într-o încăpere eliptică, un sunet emis într-un focar se reflectă spre celălalt focar. Aceeași geometrie apare la lentile și oglinzi eliptice.

Cum folosești laboratorul

Această lecție are cinci secțiuni. Poți trece de la teorie la animații, aplicații, exerciții și harta conceptuală fără să reîncarci pagina.

  • Teorie: alege conica și mișcă sliders pentru a schimba forma. Graficul și planul de tăiere se actualizează împreună.
  • Animații: modifică excentricitatea și urmărește construcția focar-directoare.
  • Exersează: primești feedback imediat și un scor final.
  • Sunet: butonul din bara de sus pornește sau oprește sunetele scurte de interacțiune.

Sugestie: folosește tabul pentru navigare și tastele săgeți pentru a schimba sliders.
