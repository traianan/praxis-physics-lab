🧪 Parabola

y = x² − 2x − 3
Rădăcinile ecuației: x₁ = −1, x₂ = 3

Punctul marcat este vârful parabolei. Pentru a > 0 parabola este deschisă în sus, pentru a < 0 în jos. Raza r și arcul nu au echivalent aici: reperele sunt x și y.

Cum interpretezi desenul?

Axa orizontală este x, cea verticală este y. Curba este parabola y = ax² + bx + c.

  • Punctele în care parabola atinge axa x sunt rădăcinile x₁ și x₂.
  • Vârful V este cel mai jos (a > 0) sau cel mai înalt (a < 0) punct al curbei.
  • Axa verticală punctată trece prin V și este axa de simetrie x = −b/2a.
  • Punctul de pe axa y este (0; c), intersecția funcției cu axa Oy.
Teorie și formule

1. Forma generală

y = f(x) = ax² + bx + c,  a ≠ 0

a, b, c sunt coeficienți reali, iar a nu poate fi zero: dacă a = 0 funcția devine liniară, nu mai este de gradul al doilea.

  • a > 0 — parabola este deschisă în sus și are un minim.
  • a < 0 — parabola este deschisă în jos și are un maxim.
  • |a| mai mare înseamnă o parabolă mai „îngustă”, mai puțin întinsă.
  • c este ordonata intersecției cu axa Oy: P(0; c).

2. Discriminantul și rădăcinile

Δ = b² − 4ac
Δ > 0

Două rădăcini reale distincte: x₁,₂ = (−b ± √Δ) / 2a. Parabola intersectează axa x în două puncte.

Δ = 0

O rădăcină dublă: x₀ = −b / 2a. Vârful atinge axa x.

Δ < 0

Nicio rădăcină reală. Parabola nu intersectează axa x (funcția nu se anulează).

Din semnul lui a și al lui Δ rezultă sensul deschiderii și poziția relativă față de axa x.

3. Vârful, simetria și forma canonică

y = a(x − h)² + k,  h = −b/2a,  k = f(h)

Prin completarea pătratului, forma generală se transformă în forma canonică. Coordonatele vârfului sunt V(h; k) = V(−b/2a ; c − b²/4a).

  • x = −b/2a este axa de simetrie a parabolei (linia verticală prin V).
  • Punctele simetrice față de axă au aceeași ordonată: f(h − t) = f(h + t).
  • k este valoarea extremă: minim dacă a > 0, maxim dacă a < 0.

4. Proprietăți și monotonie

Pentru a ≠ 0, funcția y = ax² + bx + c are următoarele proprietăți:

  • Este continuă și diferențiabilă pe ℝ; derivata este y′ = 2ax + b.
  • Monoton descrescătoare pe (−∞; −b/2a] și monoton crescătoare pe [−b/2a; ∞) dacă a > 0 (invers pentru a < 0).
  • Are un extrem în vârful V și este nebijectivă pe ℝ, dar bijiectivă de pe fiecare interval de monotonie pe imaginea sa.
  • Fiind de grad 2, are cel mult 2 rădăcini reale (teorema lui Euler–d’Alembert).
  • Prin punctele (h − t; y) și (h + t; y) trece aceeași orizontală — simetria parabolei.

Ce urmărești?
  • Coeficientul a se schimbă: a parcurge intervalul [−1,6; 1,6]. La a = 0 funcția devine liniară.
  • Punct mobil: un punct P(x; f(x)) parcurge curba de la stânga la dreapta; liniile punctate arată proiecțiile sale pe axe.
  • Rădăcinile apar: c scade treptat, Δ crește de la valori negative la pozitive, iar punctele x₁ și x₂ „ies” din vârf pe axa x.
Teorie și formule

Ce se schimbă vizual?

Schimbarea semnului lui a inversează deschiderea parabolei: dacă a trece prin 0, parabola se aplatizează într-o dreaptă (doar instantaneu — pentru a = 0 nu mai vorbim de funcție de gradul al doilea).

  • |a| crește → parabola se îngustează.
  • |a| scade → parabola se lărgește.
  • a > 0 → extrem minim; a < 0 → extrem maxim.

De ce contează Δ?

Pe măsură ce c scade, graficul coboară. Momentul exact în care parabola atinge axa x corespunde lui Δ = 0; apoi, pentru Δ > 0, apar două rădăcini reale distincte.

Δ = b² − 4ac

Aceasta este legătura directă între algebra (ecuația de gradul 2) și geometrie (intersectarea cu axa x).

🚀 Traiectoria unui proiectil

y = x·tan θ − g·x² / (2v₀²·cos²θ)
Punctul marcat este proiectilul la momentul t. t = 0,00 s

Traseul este o parabolă: componenta orizontală este uniformă, iar cea verticală este uniform accelerată (g ≈ 9,81 m/s²).

Cum interpretezi desenul?

Axa x este distanța parcursă (m), iar axa y este înălțimea (m). Curba este traiectoria proiectilului; punctul portocaliu arată poziția curentă, iar linia orizontală marchează înălțimea maximă atinsă.

Exemple rezolvate

🚀 Proiectil: săritură la înălțime

Un proiectil este lansat cu v₀ = 20 m/s la θ = 45°, cu g = 9,81 m/s².

H = (20·sin45°)² / (2·9,81) = 10,2 m
R = 20²·sin90° / 9,81 = 40,8 m
t = 2·20·sin45° / 9,81 = 2,88 s

Traiectoria este o parabolă — chiar funcție de gradul al doilea a lui x.

⬆ Minge aruncată în sus

O minge este aruncată în sus de la h₀ = 2 m, cu v₀ = 12 m/s.

h(t) = 2 + 12t − 4,905t²
tvârf = 12 / 9,81 = 1,22 s
hmax = 2 + 12²/(2·9,81) = 9,34 m
vimpact = √(12² + 2·9,81·2) = 13,5 m/s

Înălțimea în funcție de timp este exact o funcție de gradul al doilea: y = at² + bt + c.

⬇ Cădere liberă

Un corp este lăsat să cadă de la H = 45 m, fără viteză inițială.

h(t) = 45 − 4,905t²
t = √(2·45 / 9,81) = 3,03 s
v = √(2·9,81·45) = 29,7 m/s

a < 0 (a = −g/2), deci parabola este deschisă în jos — ca în cazul proiectilului.
