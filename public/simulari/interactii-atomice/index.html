Ce arată simularea

Între doi atomi neutri (de exemplu doi atomi de neon) acționează simultan două forțe:

Atracția van der Waals — norii electronici se polarizează reciproc, iar dipolii momentani se atrag. Forța scade lent cu distanța (energia ∝ −1/r⁶).
Respingerea — la distanțe mici, norii electronici se suprapun și atomii se resping puternic. Forța crește foarte brusc (energia ∝ 1/r¹²).

Energia potențială a perechii este bine descrisă de potențialul Lennard-Jones:

U(r) = 4ε [ (σ/r)¹² − (σ/r)⁶ ]

σ (parametrul de distanță) este distanța la care U = 0. ε (intensitatea interacțiunii) este adâncimea „gropii” de potențial.

Forța este panta curbei, cu semn schimbat: F = −dU/dr. Acolo unde curba coboară spre dreapta atomii se resping; unde urcă spre dreapta se atrag.

r₀ = 21/6·σ ≈ 1,12·σ    U(r₀) = −ε

La distanța de echilibru r₀ forța rezultantă este zero, iar energia este minimă. Dacă îl deplasezi și îi dai drumul, atomul mobil oscilează în jurul lui r₀. Mișcarea este ca o vibrație a unei molecule.

De reținut: cu cât ε este mai mare, cu atât atomii sunt legați mai puternic. De aceea argonul (ε mai mare) fierbe la o temperatură mai mare (87 K) decât neonul (27 K).
