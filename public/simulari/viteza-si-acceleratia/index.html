Breviar Teoretic Complet — Viteza și Accelerația (Clasa a IX-a)

Studiul cinematicii punctului material pentru mișcarea rectilinie (pe o axă Ox) și mișcarea curbilinie plană (în planul xOy), incluzând mărimile medii, mărimile instantanee (momentane) și deducerea legilor vitezei și accelerației din legi de mișcare polinomiale.

Bazele Cinematicii Vectorul de Poziție și Deplasarea

Poziția unui mobil (punct material) în raport cu un sistem de referință cartezian xOy este descrisă de vectorul de poziție r, având originea în O și vârful în poziția mobilului M(x, y):

r(t) = x(t) · i + y(t) · j |r| = √(x² + y²) [m]

Într-un interval de timp Δt = t2 − t1, mobilul trece din poziția M1(r1) în M2(r2). Vectorul deplasare Δr este coarda orientată de la M1 la M2:

Δr = r2 − r1 = Δx · i + Δy · j În mișcarea rectilinie: Δx = x2 − x1
  • Traiectoria este curba descrisă de vârful vectorului de poziție în timpul mișcării.
  • Distanța parcursă (Δs) este lungimea arcului de traiectorie; în general Δs ≥ |Δr|. Egalitatea are loc doar în mișcarea rectilinie într-un singur sens.
  • Legea de mișcare reprezintă dependența de timp a coordonatelor mobilului: x = x(t) (rectiliniu) sau x = x(t), y = y(t) (în plan).

Viteza Viteza Medie și Viteza Instantanee

1. Vectorul viteză medie (vm) caracterizează global rapiditatea schimbării poziției pe intervalul Δt = t2 − t1:

vm = ΔrΔt = r(t2) − r(t1)t2 − t1 SI: [v]SI = m/s

Orientare vm: are întotdeauna aceeași direcție și același sens cu vectorul deplasare Δr (de-a lungul coardei M1M2).

2. Vectorul viteză instantanee / momentană (v) este limita vitezei medii când intervalul de timp devine extrem de mic (Δt → 0):

v(t) = limΔt→0 ΔrΔt = r'(t) = vxi + vyj v = √(vx² + vy²)
  • În mișcarea rectilinie (axa Ox): vm = Δx / Δt, iar v(t) = x'(t). Semnul algebric (+ sau −) indică sensul de mișcare pe axa Ox!
  • În mișcarea curbilinie plană: vectorul viteză instantanee v este în orice punct tangent la traiectorie și orientat în sensul mișcării.

Accelerația Accelerația Medie și Instantanee

1. Vectorul accelerație medie (am) măsoară rapiditatea variației vectorului viteză în intervalul Δt = t2 − t1:

am = ΔvΔt = v(t2) − v(t1)t2 − t1 SI: [a]SI = m/s²

Orientare am: are direcția și sensul vectorului variație a vitezei Δv = v2 − v1.

2. Vectorul accelerație instantanee (a) este limita accelerației medii când Δt → 0:

a(t) = limΔt→0 ΔvΔt = v'(t) = axi + ayj a = √(ax² + ay²)
  • Criteriul mișcării accelerate / încetinite (frânate):
    • Dacă v · a > 0 (în 1D: v și a au același semn), modulul vitezei crește ⇒ mișcare accelerată.
    • Dacă v · a < 0 (în 1D: v și a au semne contrare), modulul vitezei scade ⇒ mișcare încetinită (frânată).

În Plan (2D) Componente: Accelerația Tangențială și Normală

În mișcarea curbilinie plană, vectorul viteză v își poate modifica atât modulul (valoarea numerică), cât și direcția. De aceea, vectorul accelerație a se descompune după două axe perpendiculare în punctul curent (triedrul Frenet):

a = at + an  ⇒  a = √(at² + an²) at ⊥ an
  • Accelerația tangențială (at): este coliniară cu viteza (tangentă la traiectorie) și măsoară variația modulului vitezei: at = dv / dt. Dacă mișcarea pe curbă este uniformă (v = const.), atunci at = 0.
  • Accelerația normală / centripetă (an): este perpendiculară pe tangentă, îndreptată întotdeauna spre interiorul (concavitatea) curbei (spre centrul de curbură C), și măsoară variația direcției vitezei:
    an = v²R = ω² · R R = raza de curbură [m]
  • Vectorul accelerație totală a este orientat întotdeauna spre interiorul (concavitatea) traiectoriei curbilinii, niciodată spre exterior!

Situații Particulare Legi de Mișcare Exprimabile prin Funcții Polinomiale

În numeroase probleme de fizică (clasa a IX-a), legea de mișcare a unui punct material pe o axă este dată sub forma unei funcții polinomiale de timp de gradul I, II sau III:

Legea de mișcare (poziția):   x(t) = A · t³ + B · t² + C · t + D   [m] A [m/s³], B [m/s²], C [m/s], D [m]

Pentru a determina legea vitezei instantanee v(t) și legea accelerației instantanee a(t), calculăm variația pe un interval foarte mic Δt → 0 (sau aplicăm regula de derivare a unui termen polinomial: din k · tn obținem k · n · tn−1):

LEGEA VITEZEI INSTANTANEE:
v(t) = 3A · t² + 2B · t + C   [m/s]
LEGEA ACCELERAȚIEI INSTANTANEE:
a(t) = 6A · t + 2B   [m/s²]
Cazul Particular Coeficienți Polinom Legea Poziției x(t) Legea Vitezei v(t) Legea Accelerației a(t)
1. Repaus A = 0, B = 0, C = 0, D = x0 x(t) = x0 = const. v(t) = 0 a(t) = 0
2. Mișcare Rectilinie Uniformă (MRU)
Polinom de gradul I		 A = 0, B = 0, C = v0, D = x0 x(t) = v0 · t + x0 v(t) = v0 = const. a(t) = 0
3. Mișcare Rectilinie Uniform Variată (MRUV)
Polinom de gradul II (a = const.)		 A = 0, B = a02, C = v0, D = x0 x(t) = a02 · t² + v0 · t + x0 v(t) = a0 · t + v0
(deoarece 2B = 2·(a0/2) = a0)		 a(t) = 2B = a0 = const.
4. Mișcare cu Accelerație Variabilă Liniar
Polinom de gradul III (supraaccelerație j = 6A)		 A ≠ 0, B, C, D oarecare x(t) = A·t³ + B·t² + C·t + D v(t) = 3A·t² + 2B·t + C
(funcție parabolică de timp)		 a(t) = 6A·t + 2B
(variază liniar cu timpul)

💡 Metodă practică pentru elevii de clasa a IX-a (fără derivate avansate): Pentru un polinom de gradul II, x(t) = B·t² + C·t + D, îl identificăm direct cu legea generală MRUV x(t) = x0 + v0·t + (a/2)·t². Rezultă imediat: poziția inițială x0 = D, viteza inițială v0 = C și jumătatea accelerației a/2 = B ⇒ a = 2B! De exemplu, dacă x(t) = 3t² − 12t + 5 [m], atunci x0 = 5 m, v0 = −12 m/s și a = 2·3 = 6 m/s², deci v(t) = 6t − 12 [m/s]. Momentul opririi (întoarcerii) se găsește punând condiția v(t) = 0 ⇒ 6t − 12 = 0 ⇒ t = 2 s.
