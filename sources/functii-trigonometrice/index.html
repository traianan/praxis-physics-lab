Cum citești desenul?

Unghiul θ se măsoară în sens trigonometric (invers acelor de ceasornic), pornind de la axa Ox pozitivă. Punctul P are coordonatele (cos θ; sin θ) pentru că cercul are raza 1.

  • sin θ este înălțimea punctului P față de axa Ox.
  • cos θ este deplasarea orizontală a lui P față de axa Oy.
  • tan θ se citește pe verticala x = 1, la intersecția cu prelungirea razei OP.
  • cot θ se citește pe orizontala y = 1, la intersecția cu prelungirea razei OP.

1. Definiții

Într-un triunghi dreptunghic, pentru un unghi ascuțit θ, raporturile dintre laturi se numesc funcții trigonometrice. Pe cercul unitate (r = 1) definițiile devin coordonate.

sin θ = cateta opusă / ipotenuză = y / r
cos θ = cateta alăturată / ipotenuză = x / r
tan θ = sin θ / cos θ = y / x,  cos θ ≠ 0
cot θ = cos θ / sin θ = x / y,  sin θ ≠ 0

Pe cercul unitate, P(cos θ; sin θ). Funcțiile sunt periodice și se pot extinde la orice unghi, nu doar la cele ascuțite.

3. Relații fundamentale

sin² θ + cos² θ = 1
tan θ = sin θ / cos θ,  cot θ = 1 / tan θ
1 + tan² θ = 1 / cos² θ
1 + cot² θ = 1 / sin² θ

Prima relație este teorema lui Pitagora scrisă pe cercul unitate: catetele sunt |sin θ| și |cos θ|, iar ipotenuza este raza 1.

Consecință: −1 ≤ sin θ ≤ 1 și −1 ≤ cos θ ≤ 1 pentru orice unghi.

4. Semne, paritate și periodicitate

  • Cadranul I: sin +, cos +, tan +, cot +.
  • Cadranul II: sin +, cos −, tan −, cot −.
  • Cadranul III: sin −, cos −, tan +, cot +.
  • Cadranul IV: sin −, cos +, tan −, cot −.
sin(θ + 360°) = sin θ,  cos(θ + 360°) = cos θ
tan(θ + 180°) = tan θ,  cot(θ + 180°) = cot θ

Funcțiile sin și cos au perioada 2π (360°), iar tan și cot au perioada π (180°). sin este impară, cos este pară: sin(−θ) = −sin θ, cos(−θ) = cos θ.

5. Grade și radiani

Un unghi complet are 360° sau 2π radiani. Legătura dintre cele două unități:

180° = π rad,  1 rad = 180°/π ≈ 57,3°
θrad = θ° · π / 180
θ° = θrad · 180 / π

Exemplu: 30° = 30·π/180 = π/6 rad ≈ 0,524 rad. Un radian este unghiul la care arcul are lungimea egală cu raza.

6. De la cerc la grafic

Dacă desfășurăm cercul unitate pe o axă orizontală, obținem graficele funcțiilor. Înălțimea punctului P devine ordonata curbei sinus, iar deplasarea orizontală devine cosinus.

y = A·sin(ωx + φ)
amplitudine |A|,  perioadă 360°/ω

Graficul sinus este o undă care pornește din 0, iar cosinus este aceeași undă deplasată cu 90°: cos x = sin(x + 90°).

Ce urmărești?
  • Sinus: înălțimea punctului P față de axa Ox se transformă direct în ordonata curbei sinus.
  • Cosinus: deplasarea orizontală a lui P se transformă în ordonata curbei cosinus.

  • Tangenta: prelungirea razei intersectează verticala x = 1; acolo citim tan θ.

De ce cercul unitate?

Pentru un cerc de rază 1, unghiul θ și arcul parcurs au aceeași măsură în radiani. Coordonatele punctului P sunt exact (cos θ; sin θ), fără niciun factor de scară.

P(cos θ; sin θ),  OP = 1

Când θ crește uniform, P se rotește uniform. Proiecția lui pe verticală oscilează între −1 și 1 — aceasta este mișcarea armonică simplă.

Legătura cu fizica

Un punct care se mișcă uniform pe un cerc are proiecții care oscilează sinusoidal. De aceea funcțiile trigonometrice descriu arcuri elastice, penduluri și undele.

x(t) = A·sin(ωt + φ)

Amplitudinea A este raza cercului, pulsația ω este viteza unghiulară, iar faza φ este unghiul inițial.

Cum interpretezi desenul?

🕰 Pendulul matematic

Un pendul cu lungimea L = 1 m oscilează cu amplitudine mică. g = 9,81 m/s².

T = 2π·√(L/g) = 2π·√(1/9,81) = 2,01 s
ω = 2π/T = 3,13 rad/s
f = 1/T = 0,50 Hz
θ(t) = θ₀·sin(ωt + φ)

Unghiul mic este o oscilație armonică descrisă de sinus.

📐 Plan înclinat

Un corp cu m = 10 kg coboară pe un plan cu α = 30° și μ = 0,2.

G = m·g = 98,1 N
G∥ = m·g·sin 30° = 49,1 N
N = m·g·cos 30° = 85,0 N
Ff = μ·N = 17,0 N
a = g(sin α − μ·cos α) = 3,21 m/s²

Descompunerea greutății folosește sinus și cosinus.

⚡ Curent alternativ

O rețea are tensiunea de vârf U₀ = 325 V și frecvența f = 50 Hz.

Uef = U₀/√2 = 229,8 V ≈ 230 V
T = 1/f = 0,02 s
ω = 2πf = 314,16 rad/s
u(t) = U₀·sin(ωt + φ)

Tensiunea rețelei este o sinusoidă cu amplitudinea U₀.
